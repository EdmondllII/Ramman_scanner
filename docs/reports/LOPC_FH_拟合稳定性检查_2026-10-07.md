# 完整 Faust–Henry A 项工作流：拟合探索与稳定性分析（2026-10-07）

当前拟合确实存在初值/局部收敛问题，同时单个窗口中的参数难以独立确定。已有接近零的声子阻尼不是数据唯一要求的结果；更低误差也不保证参数更符合物理先验。此次检查不检验仪器卷积，不增加局部背景或其他峰尾部。

本报告汇总此次新增完整 A 项路径的模型依据、首次拟合效果、物理先验对照及后续数值检查，作为下一次组会周报的取材记录。这里的“完整 A 项”指保留 Faust–Henry 因子的本征 A 项响应，不意味着已包含 B 项、仪器响应或数学模型文档中的所有扩展。历史报告涉及的旧模型与旧边界不自动适用于此次实验。

## 动机与线型模型

原有路径使用介电损耗线型，能够拟合约 735 cm⁻¹ 的 A1(LO)/LOPC 峰，但出现极大载流子阻尼与接近零的声子阻尼。此次尝试保留形变势与电光散射共同产生的 Faust–Henry 因子，检查它能否改善线型及参数解释。A 项对应原子位移和纵向电场引起的光学极化率变化；B 项对应自由载流子密度涨落，本次不研究或实施 B 项。

两条本征模型分别为：

\[
I_{\mathrm{old}}(\omega)=I_0\operatorname{Im}\left[-\frac{1}{\epsilon(\omega)}\right],
\qquad
I_{\mathrm{FH}}(\omega)=I_0A_{\mathrm{FH}}(\omega)\operatorname{Im}\left[-\frac{1}{\epsilon(\omega)}\right].
\]

新增路径是在原介电损耗上乘一次 \(A_{\mathrm{FH}}\)，不是再乘一次完整 Raman 强度。依据为[原文 PDF](../models/trnit1999_195-220.pdf)印刷页 197 式 (3.2)、(3.3)、(3.5)。公共公式位于 [raman/lineshapes.py](../../raman/lineshapes.py)，拟合接口为 [lopc_fh.py](../../raman/fitting/lopc_fh.py)，重建通过 [raman/reconstruction/lopc_fh.py](../../raman/reconstruction/lopc_fh.py) 调用同一公式。Torch 预优化使用同一代数表达式的可微实现，并有数值一致性检查。

参数 \(I_0\) 对应代码的 `amplitude`，已经是可拟合、非负的整体强度系数；无需再添加一个整体乘法系数，否则只能识别两个缩放系数的乘积。Faust–Henry 系数 \(C\) 则位于 \(A_{\mathrm{FH}}\) 内，影响两种散射贡献及其干涉。它是有符号、无量纲的相对系数，不能用强度非负要求把它限定为非负。本实验初值为 0，允许自由拟合，不把文献中的固定 C=0.55 当作当前样品已知值；C=0 恢复原介电损耗模型。

对照[数学模型文档](../models/GaN_A1LO_拟合数学模型.md)时，确认并纠正了分子中未定义的 \(\eta\)：标准 A 项的介电函数、\(\Delta\) 和 Faust–Henry 分子均使用同一个声子阻尼 \(\Gamma\)，对应 `gamma_ph`；等离激元阻尼 \(\gamma\) 对应 `gamma_p`。\(\eta\) 已从独立拟合参数中移除，此项仅纠正文档，代码原本已统一使用 `gamma_ph`。

\(\omega_L\) 是无自由载流子耦合时的 LO 声子参考频率，不等于 LOPC 曲线峰顶。若有匹配当前样品条件的独立参考，固定它有助于减少参数补偿；缺少参考时可参与拟合，但不能把观测峰顶直接当作未耦合频率。当前实验允许 \(\omega_L\) 拟合，仅要求 LO>TO，固定 \(\omega_T=533\)、\(\epsilon_\infty=9.5\)。没有为迎合先验而恢复人为窗口或参数上限。

## 无噪声模拟恢复

在相同 100 点坐标上由公共线型生成两组模拟谱：一组为 `amplitude=20, omega_l=735, omega_p=220, gamma_p=80, gamma_ph=7, C=0.55`；另一组采用本次实测多初值中的较好解。每组从真值及 3 组其他初值拟合，权重根据该组模拟数据计算。

第一组可从部分初值准确恢复真值；也存在不同参数得到约 1.29×10⁻¹⁰ 的极小误差，例如 omega_l≈738.10、omega_p≈198.24、gamma_p≈96.87。负 C 初值则得到 gamma_ph≈3.25×10⁻¹²、gamma_p≈4621.53 的解，误差约 0.000144，且 success=False。这说明很接近的曲线不等于参数恢复准确。

第二组从 C=0.55 的对照初值可恢复真值，误差约 4.18×10⁻²²；从 C=0 和 C=-0.55 初值则停在误差约 58.99 和 81.89 的近零声子阻尼解，均 success=False。即使数据完全由当前模型生成、没有噪声，当前优化流程也可能失败。

真值初值仅验证自洽性，不计作独立恢复证据；其他初值的成功与失败才用于判断初值敏感性。本次未做含噪声的恢复实验或统计置信区间。

## 对照项目已记录的物理先验

用户重点关注的是第一次 16 组初值搜索中 gamma_p≈21271 cm⁻¹ 的解，而不是扩展搜索中 gamma_p≈961831 cm⁻¹ 的最低误差解。根据[2026-09-21 组会周报第 5 节](组会周报_2026-09-21.md#5-当前拟合为什么还不能直接解释为物理参数)，逐项对照前者：

| 参数 | 已记录的参考范围 / cm⁻¹ | 该组拟合值 / cm⁻¹ | 范围判断 |
|---|---:|---:|---|
| omega_l | 730–740 | 733.258 | 范围内 |
| omega_p | 50–380 | 356.229 | 范围内，接近上端 |
| gamma_p | 230–4700 | 21270.983 | 超出，约为参考上限的 4.5 倍 |
| gamma_ph | 2–7 | 6.513 | 范围内，接近上端 |

所以，就文档明确列出的这四项范围而言，该组确实只有载流子阻尼超出。C≈0.868 和整体 amplitude 没有在该节给出明确范围，不另行判定其超界。此前“没有更合理结果”的表述应理解为未找到所有载流子参数都可信且误差低的结果，不能误写成该组所有参数都超出参考范围。

这些范围具有条件：omega_p 的 50–380 对应文献涉及的自由空穴浓度约 5×10¹⁶–3×10¹⁸ cm⁻³，同时暂取 m*=0.2m0、epsilon_inf=9.5；gamma_p 的 230–4700 对应同一质量假设和试探迁移率约 10–200 cm²/(V·s)。模型文档明确提醒，该有效质量是数值参照，不是已确认的 p-GaN 空穴质量。gamma_ph 的 2–7 也是工作范围。因此，本表给出条件性先验对照，不将其升级为当前样品已标定的硬边界。

“落在范围内”与“被光谱可靠确定”应分别报告：此次扫描和扩展搜索显示参数补偿，即使数值在参考范围内，仍需独立信息及稳定性检查才能作为材料参数解释。扩大搜索使用的初值范围也不同于本节的先验范围，不能混用。

## 仪器卷积：已实施独立探索路径

当前本征 A 项与[数学模型文档](../models/GaN_A1LO_拟合数学模型.md)第 4 节对应；本次已新建 Gaussian 卷积独立探索路径。若仪器响应近似 Gaussian，对照模型为：

\[
I_{\mathrm{obs}}(\omega)=G_{\sigma_{\mathrm{inst}}}*
\left[I_0A_{\mathrm{FH}}(\omega)\operatorname{Im}\left(-\frac{1}{\epsilon(\omega)}\right)\right].
\]

卷积应作用于整个本征 A 项响应，不能只卷积介电损耗后再乘 Faust–Henry 因子。数值实现需要扩展内部频率区间以避免边缘截断，在足够细的内部网格上计算后再采样到实验坐标；Adam、LM 和重建应采用一致模型。若标定给出 Gaussian FWHM，sigma_inst=FWHM/2.355。实验采样间隔约 0.3006 cm⁻¹ 不等于仪器分辨率。

优先使用标准样品或独立仪器标定的宽度并固定它；若仪器宽度未知，可先做候选宽度敏感性实验，但同时自由拟合仪器宽度和声子阻尼可能增加参数补偿。本次探索没有使载流子阻尼恢复到先验范围，也不能将目前异常唯一归因于仪器效应。

此次讨论按用户决定：baseline 已完成背景去除，暂不增加局部背景项；其他峰距离较远，暂不在 LOPC 目标中加入其尾部。这是本轮实验的简化假设，不是已经测定它们贡献严格为零。B 项也继续不纳入。

\[
I_{\mathrm{obs}}(\omega)=G_{\sigma_{\mathrm{inst}}}*
\left[I_0A_{\mathrm{FH}}(\omega)\operatorname{Im}\left(-\frac{1}{\epsilon(\omega)}\right)\right]
\]

卷积作用于完整本征 A 项响应。公共实现位于 `raman.lineshapes.lopc_fh_convolved`，拟合接口为 `raman/fitting/lopc_fh_convolved.py`，重建接口为 `raman/reconstruction/lopc_fh_convolved.py`。`sigma_inst` 是脚本中的固定 Gaussian 标准差，默认 1.0 cm⁻¹，单位为 Raman 位移；它没有作为自由参数拟合。卷积模型当前直接使用 LM，未调用未卷积的 Adam 预优化，因此不把不一致的目标函数混在一起。参数表使用独立文件 `fit_parameters_lopc_fh_convolved.csv`，重建、图片和评估也使用独立输出路径。

当前默认值 1.0 cm⁻¹ 是实验对照的候选设置，不是仪器标定结果。运行该路径得到的首次 `(0,0)` 结果为：全谱 RMSE=1.73519、R²=0.989740；720–750 cm⁻¹ 区间 RMSE=0.67811、R²=0.854904。它暂时劣于未卷积 FH 路径的区间 RMSE=0.60148、R²=0.885842，不能据此判断卷积模型无效；因为 Gaussian 宽度尚未由仪器或标准样品独立确定，而且卷积后的拟合没有进行多初值稳定性分析。该结果只证明新路径能够运行，不能作为最终宽度或物理参数结论。

新路径保持本项目的职责边界：拟合读取校正谱并写参数，重建读取参数并写光谱，绘图和评估只读取已有光谱结果。新路径的 `sigma_inst` 应优先替换为独立标定值；后续应在多个候选宽度下比较误差、参数先验相容性和多初值稳定性。不要同时自由拟合 `sigma_inst` 与 `gamma_ph` 后仅凭误差下降作出物理结论。

随后对该卷积路径执行了 40 组 LM 初值搜索：

```bash
python tmp/lopc_diagnostics/check_lopc_fh_convolved_stability.py
```

初值包括 docs 中的条件性参考点（\(\omega_p=50\)--380、\(\gamma_p=230\)--4700、\(\gamma_{\mathrm{ph}}=2\)--7 cm⁻¹）、当前卷积结果附近的点、不同 C 符号以及固定随机种子生成的扰动。所有拟合固定 `sigma_inst=1.0 cm⁻¹`，采用相同加权残差和 LM；初值范围不限制终值。

最低加权平方误差为 113.678377，参数为：\(\omega_L=733.290\)、\(\omega_p=1332.918\)、\(\gamma_p=314699.891\)、\(\gamma_{\mathrm{ph}}=6.048\) cm⁻¹、\(C=0.8692\)。其他近似等优解的 \(\gamma_p\) 约为 2.5×10⁴ cm⁻¹，而误差差异小于 0.001；这再次显示高阻尼分支存在参数补偿。40 个结果中没有一组同时满足此前记录的四项条件性范围（\(\omega_L=730\)--740、\(\omega_p=50\)--380、\(\gamma_p=230\)--4700、\(\gamma_{\mathrm{ph}}=2\)--7 cm⁻¹）。因此，更换初值没有找到物理上更可信的卷积解；它只能说明卷积路径的 LM 优化对初值有多个分支，不能证明 Gaussian 卷积本身错误。诊断 CSV 和摘要位于 `work/fitting/output/lopc_fh_convolved_stability/`。

## 卷积模型诊断：模拟恢复与宽度剖面

为进一步区分优化问题、参数可辨识性和模型差异，运行：

```bash
python tmp/lopc_diagnostics/diagnose_lopc_fh_convolved_model.py
```

模拟使用与拟合完全相同的卷积线型、100 个实验位移点、固定 `omega_t=533` 和 `epsilon_inf=9.5`。设定参数为 `amplitude=20`、`omega_l=735`、`omega_p=220`、`gamma_p=80`、`gamma_ph=7`、`C=0.55`、`sigma_inst=1`。分别测试无噪声和强度标准差 0.5 的加噪数据，从真值、条件性先验点和较差初值启动 LM。

无噪声模拟中，真值初值和条件性先验初值都准确恢复真值；较差初值则得到另一个几乎同样的解（加权平方误差约 2.48×10⁻⁷），其 omega_l≈750.97、omega_p≈503.39、gamma_p≈35733、gamma_ph≈6.70。这说明当前接口在理想数据上可以找到正确参数，但模型参数仍存在多个近似等价分支，初值会影响结果。

加入标准差 0.5 的噪声后，真值初值和条件性先验初值都收敛到 omega_l≈734.67、omega_p≈223.59、gamma_p≈0.000196、gamma_ph≈10.87 的分支，加权平方误差约 85.02；较差初值仍进入更远的高阻尼分支。这表明在当前 100 点窗口和强度权重下，即使数据由本模型生成，噪声也会让参数反演严重不稳定。因而真实数据的异常参数不能简单归因于程序没找到正确解，也不能仅凭模拟无噪声恢复就证明真实模型完整。

真实数据上固定 sigma_inst 并重新优化其他参数，三组初值中找到的最低加权平方误差如下：

|---:|---:|---:|---:|---:|
| 0 | 112.154 | 426.931 | 30569.247 | 6.513 |
| 0.3 | 112.298 | 358.383 | 21638.755 | 6.471 |
| 0.5 | 112.550 | 365.578 | 22719.563 | 6.397 |

## p-GaN 与 n-GaN 的参数敏感性：初步文献分析（2026-10-08）

本节记录后续文献调研与物理分析，供下载论文全文后继续核对。当前已核对出版社提交的 Harima 1998、Kozawa 1994 和 Shi 2004 论文摘要，以及项目已有 PDF 的相关正文；Demangeot 1998 仅确认书目信息，尚未取得全文。不能把摘要中的成功案例直接解释为当前样品具备同样的参数反演条件。

### 已核对的实验现象

[Harima 等（1998），Electronic properties in p-type GaN studied by Raman scattering](https://doi.org/10.1063/1.122348)系统研究空穴浓度约 5×10¹⁶–1×10¹⁸ cm⁻³ 的 p-GaN，摘要明确指出其 LOPC 线型随空穴浓度没有显著变化，难以由该峰精确评估浓度和迁移率；低频连续带则随空穴浓度增强，并归因于空穴的价带间跃迁。

[Kozawa 等（1994），Raman scattering from LO phonon-plasmon coupled modes in gallium nitride](https://doi.org/10.1063/1.356492)研究 n-GaN：电子浓度增加时 LO 带向高频移动并展宽，通过线型拟合得到的浓度与 Hall 测量吻合。该结果证明方法在相应 n 型样品条件下可以成功，不证明仅凭当前 p-GaN 单条窄窗口也能可靠反演全部参数。

项目[原文 PDF](../models/trnit1999_195-220.pdf)印刷页 199–200 的 §3.5.2 及第 202 页结论也区分两种情况：n-GaN 的拟合浓度与 Hall 测量吻合，但阻尼并非同样吻合；Mg 掺杂 p-GaN 的 A1(LO) 频移不明显，作者用较重空穴质量和强阻尼讨论这一现象，并观察到约 350 cm⁻¹ 以下的连续带。当前分析范围从 350 cm⁻¹ 开始，未覆盖这部分低频信息。原文的 p 型讨论不是仅靠 LO 峰稳定反演全部输运参数的成功证明。

这些研究支持“某些 p-GaN 条件下 LO 峰的输运参数敏感性较弱”，不支持“所有 p-GaN 都不能拟合”。浓度、弛豫时间、质量张量、晶向和信噪比均会影响适用性。

### 较重有效质量与自由载流子浓度

在相同浓度及介电常数下，屏蔽等离子频率满足

\[
\omega_p^2=\frac{ne^2}{\epsilon_0\epsilon_\infty m^*}.
\]

较大的有效质量使 omega_p 降低，因而可能减弱给定浓度变化造成的 LO 耦合峰变化。GaN 空穴质量通常比电子质量更大，并具有方向和价带依赖；一个标量有效质量只是近似，需要结合原文的测量几何核实。Mg 掺杂浓度也不等于自由空穴浓度：项目 PDF 讨论了 Mg–H 钝化及退火激活，不能把掺杂量直接代入等离子频率公式。

### 强阻尼下的参数补偿

当前介电函数的载流子贡献为

\[
-\frac{\omega_p^2}{\omega(\omega+i\gamma_p)}.
\]

当 gamma_p 远大于测量窗口内的频率时，近似为

\[
-\frac{\omega_p^2}{\omega(\omega+i\gamma_p)}
\simeq i\frac{\omega_p^2}{\omega\gamma_p}.
\]

此时载流子项主要约束 omega_p²/gamma_p，而不是分别约束二者。增大 omega_p 并同步增大 gamma_p 可以保持近似响应，这与扩展搜索中相近误差对应不同载流子参数的现象相容。该近似只针对介电函数的载流子项；完整 Faust–Henry 因子还有参数依赖，不能把它当作完整模型的严格等价变换。

必须避免“空穴较重必然阻尼更大”的错误推断。阻尼满足

\[
\gamma_p=\frac1\tau=\frac{e}{m^*\mu},
\]

由质量与迁移率共同决定；低迁移率不独立于质量假设。应比较实际弛豫时间、阻尼及其相对 omega_p 和测量频率的大小。p 型样品的高阻尼趋势需要具体样品或论文数据支持，不能仅从质量大小推出。

### 价带复杂性与其他谱段的信息

单载流子 Drude 模型以一组有效质量和阻尼表示电荷响应。空穴的价带各向异性及多个价带贡献可能限制这种近似，需要通过全文核对何种条件下必须采用更复杂响应。Harima 的低频连续带结果提示，空穴浓度信息可能在 LO 窄窗口之外更明显；这尚不证明当前 735 cm⁻¹ 峰必须加入 Fano 或 B 项。

[Shi、Ponce、Menéndez（2004），Raman line shape of the A1 longitudinal optical phonon in GaN](https://doi.org/10.1063/1.1737792)的摘要说明，LO 声子的角向色散可解释 GaN A1(LO) 的复杂线型，并用于提取本征线宽。这是与仪器 Gaussian 展宽不同的机制；应核对物镜 NA、偏振及晶向后判断相关性，不能据摘要直接套用为当前样品的解释。

### 待全文核对的阅读顺序与问题

1. Harima 1998（上述 DOI）：核对 p-GaN 的样品条件、浓度及迁移率验证方法、测量窗口和低频连续带。
2. 项目已有 PDF 第 199–200 页：核对 n/p 对照、参数定义、阻尼约定及所用质量与介电常数。
3. [Demangeot 等（1998），Coupled longitudinal optic phonon-plasmon modes in p-type GaN](https://doi.org/10.1016/S0038-1098(98)00093-3)：最直接的同类研究，待全文核对轴向/面内测量、质量各向异性、固定参数及独立验证，再判断其成功条件是否适用于当前样品。
4. Kozawa 1994：作为 n 型成功拟合的对照，核对如何使用独立 Hall 信息，以及哪些参数获得验证。
5. Shi 2004：核对角向色散模型及实验几何，与当前测量条件比较。

另需核查当前 epsilon_inf=9.5 和暂用 m*=0.2m0 的依据。项目 PDF 的 n 型分析采用 epsilon_inf=5.35，并在 p 型讨论中使用不同空穴质量；不得混淆高频/静态介电常数或电子/空穴质量。amplitude 自由时，高频介电常数的整体强度缩放可以被 amplitude 吸收，因此更换常数不保证残差或阻尼改善，但会影响由 omega_p 换算浓度的含义。暂不直接修改程序常数或先验范围，待全文与样品资料核对。

当前能确认的是本项目数值实验存在初值敏感性和参数补偿；尚不能把主因唯一归为 p 型空穴强阻尼、价带结构或某个遗漏效应。加噪模拟目前只有一组人为设定的噪声实现，不是实测噪声标定，也不是统计置信区间；其真值初值与 STARTS 第一组相同，不能当作两次独立恢复证据。后续下载全文后应据公式、样品与实验条件修订本节，而不是把本节初步解释直接当作材料结论。

## 可用于下一次组会周报的结论与待办

1. **模型探索有效但尚未完成物理验证。** 保留 Faust–Henry 因子后，首次重建的 LOPC 区间平方误差降低约 29.3%；该实验新增了一个自由参数 C，不能单凭误差下降证明物理参数可靠。
2. **优化问题确实存在。** 第一轮多初值将局部加权误差由 164.78 降至 112.15；无噪声模拟也能出现错误收敛。因此不能将异常全部归因于遗漏物理效应。
3. **声子阻尼近零不是唯一结论。** gamma_p≈21271 的较好解中，omega_l、omega_p、gamma_ph 均落在项目已记录的条件性参考范围，只有 gamma_p 明显超出；不能据旧解声子阻尼近零认定材料声子几乎无阻尼。
4. **参数补偿仍是关键问题。** 扩展 96 次拟合及 8 次精修只带来约 0.000109% 的误差改善，却将载流子参数进一步推大；仅换初值尚未找到可信的载流子参数解。有限搜索不证明全局最优或合理解不存在。
5. **下一步是标定和外部约束。** Gaussian 卷积路径已经完成初步探索，但默认宽度尚未由仪器标定，且没有改善参数先验相容性。应优先确认实际仪器响应和适用于当前样品的 LO 参考频率，再做固定标定宽度下的对照；背景、其他峰尾部及 B 项暂不加入。这些结论仍不能写成卷积已被验证有效。

写周报时需区分三种误差：首次工作流评估为已有重建总谱的未加权误差；稳定性检查优化的是局部本征 LOPC 的加权误差；扫描解的物理解释还受条件性先验及可辨识性限制。图和生产参数表目前仍对应首次 FH 工作流，诊断较好解没有替换这些文件，勿将新参数与旧图配成同一次结果。
